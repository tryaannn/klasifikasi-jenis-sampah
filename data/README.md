# Data mentah

Folder ini tidak berisi data dan tidak ikut diunggah ke repositori.

Dataset **RealWaste** diunduh dari:

- UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/908/realwaste
  (arsip langsung: https://archive.ics.uci.edu/static/public/908/realwaste.zip)
- Cermin Kaggle: https://www.kaggle.com/datasets/joebeachcapital/realwaste

Arsip: 688,5 MB, SHA-256 `1ede08b32358ee62065bcc1c8cb47a2ece04e8dff5b1fb53342bb8750895b2f3`.
